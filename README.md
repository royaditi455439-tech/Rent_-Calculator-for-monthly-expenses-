# Rent_-Calculator-for-monthly-expenses-
IT is a simple calculator which is made by python programming language 's help.  It builded for calculate monthly expenses of me and my roommates.Rent Calculator Monthly expenses 
📌 Project Overview
The Rent Calculator is a beginner-friendly Python programming project designed to calculate and divide monthly rent expenses. It helps users estimate their share of rent and manage housing costs more easily.
This project demonstrates the practical use of Python for solving everyday problems.
🎯 Objectives
Calculate monthly rent expenses.
Divide rent among people sharing accommodation.
Understand basic Python programming concepts.
Develop problem-solving and logical thinking skills.
🛠️ Technologies Used
Programming Language: Python
Concepts: Variables, user input, arithmetic operations, and output formatting.
⚙️ Features
Accepts rent-related information from the user.
Calculates rent expenses using mathematical operations.
Displays the calculated result.
Simple and beginner-friendly program.How to Run the Project
Install Python on your computer or use an online Python compiler.
Download or clone this repository.
Open the project file in a Python editor.
Run the program.
python rent_calculator.py

Note: Replace rent_calculator.py with your actual Python filename if it is different.
